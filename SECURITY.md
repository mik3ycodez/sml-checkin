# Security policy

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Please report problems through this repo's Security tab: choose **Report a
vulnerability**. Don't open a public issue for a security problem.

If **Report a vulnerability** isn't available, open an issue asking for a
private way to contact the maintainer. Don't put any details of the problem in
the issue.

Never include secrets (tokens, client secrets, session values) or member data in
a report.
